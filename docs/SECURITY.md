# Границы безопасности

Проверка по security-audit в режиме guidance: исходники API, SQLite, чтения базы,
HTTP-клиента, Vue и конфигурации контейнеров. Это ограниченная проверка, не полный
аудит или пентест; отсутствие найденной проблемы не доказывает её отсутствие.

## Модель доступа

Это локальный прототип одного оператора. Авторизации и разделения архива между
пользователями нет. Compose публикует оба порта только на 127.0.0.1: при публикации
на всех интерфейсах сторонний пользователь сети мог бы прочитать общий архив
и заявки. Для публичного сервиса нужны аутентификация, права на архив, TLS,
ограничение частоты запросов и политика удаления данных. CORS не заменяет права.

## Реализованные меры

- Оба процесса в контейнерах работают без root, с read-only rootfs, без Linux
  capabilities и с no-new-privileges. Запись — в ограниченный tmpfs и том приложения.
- База монтируется read-only, не включается в образ или репозиторий. .env и
  локальные инструменты агента исключены из build context.
- Архив ZIP читается без распаковки: ограничены размер, число записей и объём
  текста, запрещены traversal, символические ссылки и опасные пути.
- SQL параметризован, операции записи транзакционные. Число координационных
  блокировок ограничено, вместо накопления по каждой новой сессии.
- Запросы и контакты валидируются; заявка требует согласия и защищена от дубликата.
  nginx ограничивает тело запроса 64 КБ; backend-порт предназначен только оператору.
- Текст отображается Vue-интерполяцией, без HTML. Ошибки API не раскрывают
  провайдерские ответы, ключи или traceback. Отладка показывает источники и время.
- Модель получает документы и реплики как данные. Источники проверяются по ID;
  это не доказательство истинности и не полная защита от prompt injection.
- HTTP redirects к провайдеру выключены, число повторов ограничено. URL провайдера
  задаёт доверенный оператор, пользователь чата его не меняет.

## Секреты и данные

Используйте вымышленные контакты. Реальная база, вопросы, диалоги, индексы и ключи
не коммитятся. Провайдер модели получает историю и контекст: подключайте только
разрешённый сервис. Внешняя отправка заявок отсутствует.
Том app-data содержит историю; доступ к Docker/хосту даёт доступ к ней.

Зависимости Python полностью закреплены в requirements.lock, прямые — в
requirements.txt; Node — package-lock.json. Это воспроизводимость, не гарантия
отсутствия CVE. Полная сверка advisory-баз и сканирование контейнеров не выполнены.
Функциональные тесты с синтетикой разрешены пользователем локально; внешний API
при финальной проверке не вызывался.
