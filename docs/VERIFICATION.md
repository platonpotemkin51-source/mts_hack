побайтно совпадают с архивом hybrid-evidence (61.664).
Проверен SHA-256 исходного архива, см. [BEST_SUBMISSION](../evaluation/rag/BEST_SUBMISSION.md).

Точка входа CSV оставлена в корневом solution.py, ядро — в energytool/.
После исправления структуры повторно прошли 98 backend/packaging и 61 RAG-тест,
14 браузерных тестов, Docker-сборка и полный smoke с перезапуском. Плоский ZIP дополнительно
импортируется вне репозитория, без возможности случайно использовать пакет.

## Выполнено

- 97 тестов backend/диалога/транспорта/CSV и 61 тест RAG прошли на хосте и внутри
  Python 3.11 Docker с закреплёнными зависимостями. Контейнерные тесты без сети.
- Дополнительная проверка упаковки: плоский ZIP во временном каталоге, исходники
  без изменений, секреты исключены. Это не создание финального архива для сдачи.
- `npm run build`: TypeScript + Vite production build, успешно и на хосте, и в Docker.
- `npm test`: 14 браузерных сценариев прошли (Google Chrome / Playwright).
- Оба production-образа собраны; оба процесса non-root, healthchecks проходят.
  При первом запуске обнаружена и исправлена ошибка временных директорий nginx
  на read-only rootfs. Проверка проведена повторно после исправления.
- Браузерный smoke через nginx → FastAPI → BM25 → синтетический HTTP-прокси:
  источник и время, продолжение сессии, исправление объекта, согласие и заявка,
  архив, мобильная ширина. Скриншоты UI просмотрены на desktop и mobile.
- `python3 scripts/smoke_docker.py`: отдельный Docker-проект с вымышленной базой,
  проверка изоляции нового диалога и архива после перезапуска backend; успешно.
  После проверки удалены только тестовые контейнеры и их тестовый том.
- Проверка безопасности по исходникам: [SECURITY](SECURITY.md).

## Воспроизведение

Команды unit/UI-тестов — в [README](../README.md).
Полный тест Docker без API-ключа:

```sh
python3 scripts/smoke_docker.py
```

Нужны Docker Compose v2.24.4+ (override volumes), свободные порты 5187/8187,
интернет для сборки образов. Скрипт создаёт только собственные синтетические
данные в runtime/verification. Для браузерного smoke нужен Chrome и
запущенный синтетический стек: `LIVE_STACK_SYNTHETIC=1 LIVE_URL=http://127.0.0.1:5187
node scripts/smoke-live.mjs` из frontend/. Основной скрипт сам останавливает стек.

## Границы доказательства

Синтетическая модель проверяет интеграцию и хранение, а не достоверность ответов.
Внешние API и реальная генерация при финальном оформлении не вызывались.
Локальный Groq с BM25 отличается от платформенной Qwen с гибридом.
Полный security-аудит, advisory/CVE-скан и нагрузочные испытания не выполнялись.
Презентация сохранена из предыдущей версии и требует сверки перед защитой.
