# Демонстрация Energytool

## Подготовка

Запуск UI описан в `frontend/README.md`. Для итогового показа:
`VITE_USE_MOCK_API=false`, работающие backend, база знаний и доступная модель.
Убедиться, что баннера MOCK нет. Отсутствие баннера само по себе не доказывает
работу RAG: проверить реальные источники и ответы на шаге 2.
Ниже собственные синтетические реплики команды, без содержимого базы организаторов.

## Показ на 3–5 минут

1. **Задача.** «У нас склад. Хотим разобраться с расходами на электроэнергию
   и наладить учёт. С чего начать?» Показать ответ по существу и карточку справа.
   Неизвестные сведения должны оставаться незаполненными.
2. **Уточнение и доказательства.** Включить «Отладка», ответить на уточнение
   консультанта. Спросить: «Какие решения из вашей базы подходят и почему?»
   Раскрыть источники и время под ответом. Проверить рекомендацию по реально
   найденному материалу. Если материала недостаточно — показать честное ограничение;
   не зачитывать заранее придуманные обещания, цены и характеристики.
3. **Исправление.** «Уточню: это офис, а не склад. Главная задача — разобраться
   с учётом». Карточка должна отразить новые сведения из backend, без старого объекта.
4. **Без контактов.** При предложении заявки нажать «Продолжить без контактов».
   Написать: «Телефон пока оставлять не хочу. Какие данные об объекте подготовить?»
   Чат продолжает работать, предложение контактов повторно не навязывается.
5. **Заявка.** Нажать «Оформить заявку». ФИО: «Тестовый Клиент», телефон:
   «+70000000000», компания: «Демо-компания». Отметить согласие и сохранить.
   Показать серверное резюме. Это сохранение внутри прототипа,
   внешней отправки менеджеру или CRM нет.
6. **Изоляция и архив.** Нажать «Новый диалог». Переписка и карточка пустые.
   Написать: «Хочу обсудить другой объект». Открыть «Архив диалогов»:
   показать прошлую переписку с заявкой и новую без заявки. Чтение не возобновляет сессию.
7. **Закрытие.** Вернуться в «Консультация», закрыть чат крестиком, открыть снова.
   Активный контекст пустой, старый разговор остаётся в архиве.

## Отдельная демонстрация без backend

Явно включить mock. Первая реплика возвращает исходный fixture про склад,
последующие — обозначенный демонстрационный ответ и предложение формы.
Работают новый диалог, отказ, позднее согласие, синтетическая заявка и архив вкладки.
Mock не меняет карточку по смыслу реплик, не ищет базу и не генерирует ответы.
Шаги 2–3 на нём не являются приёмкой качества консультации.
