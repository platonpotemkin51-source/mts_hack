# Демонстрация — зона Даниила

После первого работающего сценария подготовить короткий показ: задача клиента → полезный ответ со ссылкой на базу → уточнение → заполненная карточка → согласие → заявка → новый диалог → архив прежней сессии.

Добавить точные шаги, вымышленные входные данные и ожидаемые признаки успеха после реализации. Не копировать тесты организаторов или продуктовые фрагменты в публичную документацию. Известные сбои и недоступные функции обозначать прямо.
