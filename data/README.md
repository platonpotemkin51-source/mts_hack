# Локальные входные материалы

Ссылки — `../docs/SOURCES.md`. Скачай вручную `knowledge-base.zip` и демонстрационные вопросы в этот каталог. Для локального CSV-прогона копию demo-вопросов можно назвать `questions.csv`.

При автоматической проверке эти файлы предоставляет платформа через `DATA_DIR` (по умолчанию `data`). Не включать их в сабмит. Все файлы `data/`, кроме этой инструкции, игнорируются Git.

Исходная база, CSV, распакованные документы, их копии и индексы с текстом базы не публикуются. Результаты и SQLite хранить в игнорируемом `runtime/`. Не переносить закрытые данные в другую отслеживаемую папку.

## Поиск локально

`load_documents` принимает `knowledge-base.zip` без распаковки либо каталог
Markdown UTF-8. Все вложенные `.md` читаются полностью; символические ссылки,
опасные пути и превышение лимитов вызывают ошибку. Импорт модулей не читает
базу и не обращается к сети.

После размещения базы пример вызова и проверки — в
[`evaluation/rag/README.md`](../evaluation/rag/README.md).
Локальная разметка retrieval хранится в `evaluation/rag/local/`, подробный
отчёт — в `runtime/evaluation/`. Оба каталога игнорируются Git.
