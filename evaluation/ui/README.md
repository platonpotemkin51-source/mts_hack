## Ограничения и интеграция

Настоящий backend в этой ветке реализует только health. Реальные LLM/RAG,
исправление карточки по смыслу, сохранение SQLite и фактическое серверное резюме
этим прогоном не подтверждены. HTTP-fixtures проверяют транспорт/отрисовку,
а не реализацию сервера. В mock карточка фиксирована, нет поиска и генерации.

Docker/nginx подготовлены, но Docker/Compose не запускались.
Полный сценарий после объединения должен пройти Платон вместе с командой.
От Платона нужны все маршруты контракта, API-origin/CORS либо same-origin proxy,
серверное хранение, обработка потерянных запросов и согласование безопасных повторов.
От Артёма через backend нужны настоящие источники и поисковые результаты.

При неопределённой ошибке чата повтор заблокирован до нового диалога:
контракт не даёт идентификатора запроса/идемпотентности. История остаётся доступной.
При закрытии вкладки до получения первого server ID закрытие на сервере не гарантировано.
Ответы старого поколения в новый чат не попадают.
