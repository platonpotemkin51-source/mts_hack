# Проверка интерфейса

16.11.2026: production build и 14 Playwright-тестов прошли в Google Chrome.
Порты тестов — 5183/5184. Проверяются клавиатура, повтор запроса, отказ от
контактов, согласие, заявка, архив, сброс, ошибки API, экранирование текста
и мобильная ширина. Скриншоты desktop.png / mobile.png — синтетический UI.

Отдельный браузерный smoke прошёл через настоящий Docker API/RAG/SQLite
и явно синтетическую модель: источники, время, смена объекта, заявка и архив.
Это интеграционная проверка, не проверка качества модели.
