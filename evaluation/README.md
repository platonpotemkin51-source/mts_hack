# Проверка качества

| Папка | Владелец | Что проверяет |
| --- | --- | --- |
| `rag/` | Артём | Найденные документы/ограничения, ошибки поиска, время и память |
| `backend/` | Платон | История, заявки, консультация, CSV и время прогона |
| `ui/` | Даниил | Полный сценарий, ошибки, новый диалог, адаптивность |

Добавлять собственные синтетические сценарии и агрегированные отчёты. Исходные вопросы организаторов, ответы и фрагменты базы — только в локальных данных. Для закрытых результатов использовать `runtime/evaluation/` или подпапку `local/`, которую игнорирует Git.
