## Проверки и ограничения

97 backend/CSV-тестов прошли на кандидате. Это проверка совместимости кода,
не роста качества. На локальном Groq проверены только синтетические тексты;
настоящие Qwen и embeddings доступны только на платформе. Hybrid retrieval
с настоящими embeddings, конкурсные ответы и публичный балл этого коммита
не проверены. Пользователю остаются три платформенные попытки; отправку
выполняет только команда. Кандидат промпта пригоден для **одного** отдельного
сравнения с контролем, без включения второго прохода или других изменений.
