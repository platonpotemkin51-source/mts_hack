## Что включено по умолчанию

BM25 + целевой добор доказательств из предыдущего эксперимента. Исправления
контекста диалога, числовых уточнений, выбора безопасного вопроса и резюме.
Пробелы/регистр в ID `C1` не превращают подтверждённый ответ в общий отказ;
несуществующие и частично совпавшие ID не допускаются.

`ANSWER_REVIEW=0` оставляет один обычный проход генерации (с прежними ограниченными
повторами при ошибках). `ANSWER_REVIEW=1` — отдельный эксперимент с селективной
проверкой черновика; готов к техническому запуску, но не измерен на настоящей Qwen.
Менять вместе с ним поиск, токены и промпт для сравнения не нужно.
